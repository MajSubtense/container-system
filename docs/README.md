# 网格容器模块 · 文档

往 **M×N** 的格子里摆 **m×n** 的矩形块。支持一次方向调整（0 ↔ 90）、自动放入
（先试放、放不下再**重排**已有块）、格间搬运（搬走 / 合并 / 换位）、跨容器搬运、
以及**不需要物品表**的存读档。

这份文档按**读者的下一步**分，不按代码模块分。

---

## 三十秒

```bash
# 1. 跑 demo（主场景已设为 demo/demo.tscn，直接 F5 也行）
godot --path .

# 2. 模型判据：不起窗口、不建场景，几秒跑完
godot --headless --path . --script res://tests/run_tests.gd
# → 14 组 / 17412 条断言 / 0 失败

# 3. demo 接线冒烟（"拿起 → 拖到另一块板 → 松手"）
godot --headless --path . --script res://tests/demo_smoke.gd
```

demo 里：左键拖动、拖到另一块板上、`R` 换方向、右键原地转。
七个按钮演示拾取、双向搬运、整理（重排）、存档 / 读档、清空。

## 目录

```
container-system/
├── README.md          ← 入口页 + 边界表（这个模块管什么、不管什么）
├── docs/              ← 你正在看的东西
├── scripts/           ← 模块本体：8 个 .gd = 8 个概念，整目录拷走就能用
├── demo/              ← 游戏侧参考实现（不属于模块）：物品表、规则、视图、拖拽
├── tests/             ← run_tests.gd（模型判据）+ demo_smoke.gd（接线冒烟）
└── refs/              ← 旧项目快照，只读参考，不参与构建
```

`scripts/` 里没有任何绘制代码、没有任何物品定义。**判据会检查这件事**
（`run_tests.gd` 第 10 组会读 `cell_grid.gd` 的源码，断言里面不出现 `ItemDef` /
`max_stack` / `def_id` 这类词）。

| 文件 | 概念 |
|---|---|
| `grid_shape.gd` | 纯几何：归一化、旋转、相交、展开成格 |
| `placement.gd` | 一条占位：锚点 + 形状 + 方向 + **不透明 payload** |
| `cell_grid.gd` | `CellGrid`：M×N 网格本体 + 位置索引 |
| `place_finder.gd` | 找位策略的接口（Strategy） |
| `first_fit_finder.gd` | 默认策略：行优先、正放优先 |
| `repacker.gd` | `GridRepacker`：允许挪动已有块的重排（离线装箱） |
| `grid_ops.gd` | `GridOps`：搬 / 转 / 批量放入的唯一入口 |
| `grid_layout.gd` | `GridLayout`：格 ↔ 像素的纯换算 |

## 运行环境

- Godot **4.7**（用 4.7.2 验证；4.x 的 API 没有用到 4.7 独有特性，但没有逐版本回归）
- 纯 GDScript，无插件、无 autoload、无单例
- 8 个脚本都带 `class_name`，拷进项目任意目录都能被全局认到
  （新加脚本后编辑器没认出来时，重启编辑器或跑一次 `godot --headless --path . --import`）

## 许可与改动

模块代码在 `scripts/`，可以整目录复制。改动前请先读 [07 · 设计笔记](07-design.md)：
里面每条"为什么不那样做"都对应一个已经踩过的坑，判据第 10 / 14 组会挡住回头路。
